# KOSPI Archive Wall

An interactive dark-gallery infographic wall for exploring key KOSPI milestones from 1980 to May 15, 2026.

## Deploy

This is a static site. Deploy the repository root to Vercel with:

- Framework Preset: Other
- Build Command: none
- Output Directory: `.`

## Local Preview

```sh
python3 -m http.server 4174
```

Then open `http://127.0.0.1:4174`.
